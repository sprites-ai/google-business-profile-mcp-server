# Google Business Profile MCP Server

The Sprites MCP server connects Google Business Profile to any MCP client, including multi-location accounts. Ask how a location is performing in local search, post an update, or fix the details that are costing you the map pack — with every change approved before it publishes.

## Quick start

1. **Connect Google Business Profile in Sprites.** Sign up at [sprites.ai](https://www.sprites.ai) and connect Google Business Profile once in the Sprites integrations menu. Start a trial from the Sprites site.
2. **Add the server to your client** with the URL `https://mcp.sprites.ai/mcp` (one endpoint for every client and every channel).
3. **Sign in.** Your client opens the Sprites consent screen. Sign in with the account your channels are connected to and approve.
4. **Ask.** Try: "With Sprites, how did each of our locations perform in local search last month?"

## Setup by client

### Claude (claude.ai and Claude Desktop)

Works on Free (one custom connector), Pro, Max, Team and Enterprise.

1. Settings, then Customize, then Connectors. On Team and Enterprise an Owner adds it once under Organization settings, Connectors.
2. Click **+**, then **Add custom connector**. Name it `Sprites` and paste `https://mcp.sprites.ai/mcp`. Leave Advanced settings empty.
3. Click **Connect**, sign in to Sprites and approve.

Claude draws the Sprites approval card in the chat, so you can edit a budget or a headline in place and approve it.

### Claude Code

```bash
claude mcp add --transport http sprites https://mcp.sprites.ai/mcp
```

Then type `/mcp` inside Claude Code to finish the browser sign-in.

### ChatGPT

Plus, Pro, Business, Enterprise and Edu, on the web app. Not available on Free.

1. Settings, Security and login: turn on **Developer mode**. On Business and Enterprise an admin has to allow it first.
2. Settings, **Plugins** (formerly Connectors), then **+** to create an app.
3. Name `Sprites`, MCP server URL `https://mcp.sprites.ai/mcp`, Authentication **OAuth**. Tick the trust box and click Create.
4. Connect the app and sign in to Sprites.

### Cursor

`~/.cursor/mcp.json` (every project) or `.cursor/mcp.json` (one repo):

```json
{
  "mcpServers": {
    "sprites": {
      "url": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Cursor discovers the Sprites authorization server from the endpoint and opens a browser to sign in.

### Codex

```bash
codex mcp add sprites --url https://mcp.sprites.ai/mcp
codex mcp login sprites
```

Or by hand in `~/.codex/config.toml`:

```toml
[mcp_servers.sprites]
url = "https://mcp.sprites.ai/mcp"
auth = "oauth"
```

### VS Code and GitHub Copilot

`.vscode/mcp.json`. The top-level key is `servers`, not `mcpServers`, and a remote server needs `"type": "http"`:

```json
{
  "servers": {
    "sprites": {
      "type": "http",
      "url": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Run **Auth** above the entry, sign in, then switch Copilot Chat to **Agent** mode. Ask mode does not call MCP tools.

### Gemini CLI

`~/.gemini/settings.json`. Use `httpUrl`; a `url` entry is treated as SSE:

```json
{
  "mcpServers": {
    "sprites": {
      "httpUrl": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Restart the CLI; the first call opens the sign-in. Check with `gemini mcp list`.

## What it can read

- Every location on the account and its profile fields
- Views on Search and Maps, calls, direction requests and website clicks
- The queries surfacing each listing
- Reviews and their ratings

## What it can change (with your approval)

- Posts, offers and events, per location, and replies to reviews
- Profile fields: hours, description, website and phone
- Each one approved before it publishes

Every change arrives as an approval with the before and after. In Claude and ChatGPT it is a card you can edit
in place. In clients without cards, Sprites returns the change written out with a gate id, and applies it only
after you confirm (`approve_change`). Nothing is applied by the model on its own.

## Permissions

- **business.manage.** The one OAuth scope the Business Profile APIs use, for locations, reviews and posts.
- **API access request.** Google approves each Cloud project for the Business Profile APIs through an access request form before the APIs even appear in the console.
- **Account and location IDs.** Every call names the account and the location it acts on.
- **What Sprites asks for.** Google sign-in for business.manage, then you pick the locations Sprites may work on.
- **What you skip.** You file no API access request and create no Cloud project.
- **Your AI client never holds a platform credential.** It holds a Sprites OAuth token bound to `https://mcp.sprites.ai/mcp`.

## Tools

The server exposes 20 tools to the model: 6 read tools and 14 write tools. Write tools that touch an ad account or a site only propose; nothing reaches either until you approve it. The tools that do the Google Business Profile work:

| Tool | What it does on Google Business Profile |
|---|---|
| `analyze` | Views, searches, calls and direction requests per location. |
| `optimize` | The missing profile fields costing you local rank. |
| `change` | One named edit: hours, a description, the website or phone. |
| `run_task` | Every location on the account, with what each is missing. |

Google Business Profile requests use `channel: gbp`. Name another channel, or `all`, to compare.

Every task tool takes the same input: `goal` (the request written to stand on its own: Sprites sees only this
string, not the chat), `title` (a short label), `channel`, and `today` (the user's local date, so "last 30 days"
resolves correctly). Long tasks return a run id; `task_status` collects the result and `cancel_task` stops it.

## FAQ

**Is this a server I have to host?**
No. It is a hosted remote MCP server. Paste `https://mcp.sprites.ai/mcp` into your client and sign in.

**How does it compare with other Google Business Profile MCP servers?**
Google publishes no Business Profile MCP server. Its official servers cover Google Ads and Google Analytics, not local listings, so every Business Profile server is a third party on the same public API. Small community servers such as A1-x-Tech/mcp-google-business and Insightful-Pipe/google-my-business-mcp-server cover reviews, replies and posts. Each runs on a Google Cloud project that Google has granted Business Profile API access. Sprites reads every location’s views, calls, direction requests, search queries and reviews, and writes posts, offers, events, review replies and profile fields (hours, description, website, phone), each approved before it publishes.

**Does it handle more than one location?**
Yes. Multi-location accounts list every location, report per location, and pin to one for the length of a conversation so an answer cannot drift to the wrong store.

**Can it reply to reviews?**
It reads reviews and can draft a reply, but the reply publishes only on your approval — a review response is not something to automate blind.

**Will it change my business hours by itself?**
No. Profile field changes are approvals like any other write, with the before and after stated.

**Is Google Business Profile the same as Google My Business?**
Yes — Google renamed it. Guides still using the old name are describing the same product.

**Which agent suits local work best?**
Claude or ChatGPT, because a per-location post reads better as a card you can edit than as text you have to re-dictate.

**Does it cover other channels?**
Yes. The same URL reaches Google Ads, Meta Ads, LinkedIn Ads, TikTok Ads, Reddit Ads, Microsoft Advertising,
Apple Ads, GA4, Search Console, Shopify, SEO and AI visibility, and Google Business Profile, for whatever is
connected in Sprites. See [ads-mcp-servers](https://github.com/sprites-ai/ads-mcp-servers).

**How much does it cost?**
The connector is included in every Sprites plan, and every plan starts with a short trial. See sprites.ai for current plans. Google Business Profile is billed by its own vendor as usual.

**The client says it has no tools, or every call is unauthorized.**
Remove the server, re-add it with exactly `https://mcp.sprites.ai/mcp`, and sign in again. Grants are bound to that one URL.

**How do I revoke access?**
Disconnect the connector in your client, or remove the connection in Sprites. The next tool call fails closed.
